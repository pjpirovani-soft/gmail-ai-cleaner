# GLOSARIO — gmail-ai-cleaner

- Inbox Zero: bandeja vacía o solo con correos accionables.
- ÚTIL: correo funcional que debe conservarse (trabajo, banco, familia, 2FA).
- ARCHIVABLE: correo con valor histórico (facturas, confirmaciones).
- DESECHABLE: correo sin valor (spam, promos, newsletters viejos).
- Regla de oro: si no encaja con certeza → DESECHABLE.
- Fallback heurístico: clasificación por palabras clave si Gemini no está disponible.
- Mock: correo simulado, no real de Gmail.
- GEMINI_API_KEY: clave de Google AI Studio para clasificación IA.
- M3: Material Design 3.
- PWA: Progressive Web App.
- CDD: Context-Driven Development (metodología del studio).
